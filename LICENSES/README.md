This directory accompanies Designer binary distributions. The project itself is
licensed under AGPL-3.0-or-later; see the top-level `LICENSE`. Component names,
versions, linkage, and source locations are listed in `THIRD_PARTY.md`.

| `MPL-2.0.txt` | Eigen and Spectra |
| `Boost-1.0.txt` | Boost, Clipper2, and the Clipper 1 inside `designer_adaptive` |

| `stb.txt` | stb_image and stb_image_write |
| `Font-Awesome-Free.txt` | Font Awesome 6 Free font |
| `IconFontCppHeaders.txt` | generated Font Awesome codepoint header |
